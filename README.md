# Dissertation_Analysis
# South Yorkshire Accessibility and Economic Inactivity

MSc dissertation analysis exploring the spatial relationship between
cumulative accessibility disadvantage and economic inactivity in
South Yorkshire, England.

## Files
- `01_data_preparation.Rmd` — data cleaning and composite score construction
- `02_phase1_national_analysis.Rmd` — national-scale ranking and Moran's I
- `03_phase2_south_yorkshire.Rmd` — South Yorkshire case study, LISA, comparisons
- `methodology_draft_v10.docx` — Chapter 3 (Methodology)
- `chapter4_results.docx` — Chapter 4 (Results)

## Data
Raw data are not included in this repository as they are all openly
available. Sources:
- Economic inactivity: Census 2021, table TS066 (ONS Nomis)
- Deprivation: Index of Multiple Deprivation 2019, File 2 (MHCLG)
- Accessibility: GB Accessibility Indicators (Verduzco Torres and McArthur, 2024)
- Rural Urban Classification: RUC 2021 (ONS)
- Boundaries: ONS LSOA 2021 boundary shapefile (BGC V5)
- Car ownership: Census 2021, table TS045 (ONS Nomis)

Processed data (`data/processed/`) generated by `01_data_preparation.Rmd`
are included in this repository for reproducibility.
